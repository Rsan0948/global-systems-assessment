# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature on the repository's Security tab. Include the affected file or component, the steps needed to reproduce the issue, the likely impact, and any suggested mitigation you have already tested.

You should receive an acknowledgment within seven days. A fix timeline will depend on severity, complexity, and whether an upstream dependency is involved. Please allow time for a patch before sharing the issue publicly.

## Supported code

Security fixes are applied to the default branch. Historical tags, frozen research artifacts, and archived experiments are preserved for reproducibility and may not receive backports.

## Research data

The repository is designed for public and aggregate research data. Do not submit private personal data, credentials, access tokens, unpublished confidential records, or material that cannot legally be redistributed.
